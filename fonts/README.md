# Yerel yazı tipleri

Google Fonts: DM Sans (normal, 400–700 değişken ağırlık) ve Instrument Serif (normal/italik, 400).

Kaynaklar:
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/instrumentserif

DM Sans optik boyut ekseni 14 değerinde sabitlenmiştir. FontTools ile U+0020–017F, U+2000–206F, U+2190–21FF, U+2212, U+221E, U+FEFF ve U+FFFD kapsamına alt kümelenip WOFF2 olarak sıkıştırılmıştır. Türkçe karakterler korunur. OFL lisans metinleri bu klasörde yer alır.
